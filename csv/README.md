# CSV Data Files

This directory contains all CSV data files generated by the Radiation-Tolerant Machine Learning Framework.

## File Categories

### Validation Results
- `validation_LEO_10.csv` - Low Earth Orbit validation results (10% radiation)
- `validation_GEO_10.csv` - Geosynchronous Orbit validation results (10% radiation)
- `validation_ISS_10.csv` - International Space Station validation results (10% radiation)
- `validation_JUPITER_10.csv` - Jupiter environment validation results (10% radiation)
- `validation_JUPITER_20.csv` - Jupiter environment validation results (20% radiation)

### Radiation Testing Results
- `radiation_test_10_enabled.csv` - Radiation testing with protection enabled (10% radiation)
- `radiation_test_10_disabled.csv` - Radiation testing with protection disabled (10% radiation)
- `radiation_test_50_enabled.csv` - Radiation testing with protection enabled (50% radiation)
- `radiation_test_50_disabled.csv` - Radiation testing with protection disabled (50% radiation)
- `radiation_test_100_enabled.csv` - Radiation testing with protection enabled (100% radiation)
- `radiation_test_100_disabled.csv` - Radiation testing with protection disabled (100% radiation)

### Monte Carlo Simulation Results
- `monte_carlo_results.csv` - Main Monte Carlo simulation results
- `rs_monte_carlo_results.csv` - Reed-Solomon Monte Carlo results
- `monte_carlo_comparison.csv` - Comparison of different Monte Carlo approaches

### Monte Carlo Test Results (Standard)
- `mc_test_standard_NONE_LEO.csv` - Standard Monte Carlo tests with no protection in LEO
- `mc_test_standard_MINIMAL_LEO.csv` - Standard Monte Carlo tests with minimal protection in LEO
- `mc_test_standard_MODERATE_LEO.csv` - Standard Monte Carlo tests with moderate protection in LEO
- `mc_test_standard_HIGH_GEO.csv` - Standard Monte Carlo tests with high protection in GEO

### Monte Carlo Test Results (Wide)
- `mc_test_wide_MODERATE_LEO.csv` - Wide Monte Carlo tests with moderate protection in LEO
- `mc_test_wide_HIGH_GEO.csv` - Wide Monte Carlo tests with high protection in GEO
- `mc_test_wide_SPACE_OPTIMIZED_MARS.csv` - Wide Monte Carlo tests with space-optimized protection on Mars

### Scientific Validation
- `scientific_validation_results.csv` - Scientific validation results
- `scientific_validation_results_calibrated.csv` - Calibrated scientific validation results

### Quantum Analysis
- `quantum_enhancement_results.csv` - Quantum enhancement analysis results
- `summary_stats.csv` - Summary statistics from quantum analysis

### Performance and Comparison Results
- `protection_methods_comparison.csv` - Comparison of different protection methods
- `systematic_fault_results.csv` - Systematic fault injection results
- `quick_anomaly_results.csv` - Quick anomaly detection results
- `quick_compression_results.csv` - Quick compression analysis results
- `leo_simulation_results.csv` - LEO simulation results
- `extreme_conditions_results.csv` - Results from extreme condition testing

### Training and Environment
- `training_results.csv` - Neural network training results
- `environment_comparison.csv` - Environment comparison data

## Usage

These CSV files contain experimental data, validation results, and performance metrics from the radiation-tolerant machine learning framework. They can be used for:

- Performance analysis and comparison
- Validation of protection mechanisms
- Research and development
- Documentation and reporting

## Data Format

Most files contain columns for:
- Test parameters (radiation level, protection method, etc.)
- Performance metrics (accuracy, error rates, overhead)
- Statistical measures (mean, standard deviation, confidence intervals)
- Timestamps and test conditions

Refer to individual files for specific column definitions and data formats.
